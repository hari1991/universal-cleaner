# Universal Cleaner

A cross-platform GUI application built in Go that helps developers clean up build artifacts, dependencies, and temporary files from development projects.

## Core Purpose
- Clean build artifacts and temporary files across multiple programming languages
- Provide both GUI and CLI interfaces for different use cases
- Support cross-platform deployment (Windows, macOS, Linux)

## Key Features
- **Multi-language support**: Node.js, Java, Python, Rust, Go, C/C++, Docker, IDE files
- **Safety-first approach**: Preview before deletion, confirmation dialogs, selective deletion
- **Dual interface**: GUI for interactive use, CLI for automation and scripting
- **Size calculation**: Shows space usage for informed decision making

## Target Users
Developers who need to reclaim disk space by cleaning up build artifacts and temporary files from their development projects.
